# Project screenshots

Save each project screenshot here (for example `my-app.webp`), then point to it in
`src/data/content.js` with `image: '/projects/my-app.webp'`.

Best results: about 1200 x 600 px (2:1, wide), WebP or JPG, under 200 KB each.
The top of the screenshot is what shows on the card, so capture the page from the top.
